# OUNIROBOT 监控固件

为 AI Passport 的 240 × 320 屏幕提供独立 Wi-Fi 监控。应用和 BSP 源码独立保存在此目录，不包含上游演示程序。

## 首次使用

1. 开机后连接屏幕显示的 WPA2 热点，密码由设备随机生成。
2. 浏览器打开 `http://192.168.4.1`，填写 2.4 GHz Wi-Fi 名称、密码和 Grafana 组织 1 的专用 Viewer 只读服务账户令牌，不要填写管理员密码。
3. 保存后自动重启，关闭配网热点，通过 NTP 校时，再用证书校验的 HTTPS 每 15 秒查询 `https://monitor.ounirobot.com/api/ds/query`，数据源为 `prometheus`。不接受重定向。
4. 上下键选择节点，OK 切换概览和详情，长按 OK 重新进入配网并替换凭证。

显示 CPU 五分钟平均值、内存、根分区磁盘、节点 exporter、RDS/Redis exporter 可用性。Exporter 在线不等同于数据库事务健康。达到 80% 显示黄色，90% 显示红色；这是本机显示阈值，不是 Grafana 告警规则。缺失数据不显示为正常。查询失败保留上次成功快照，底部显示样本年龄，断网或样本超过 60 秒标记过期。本版不含历史曲线、容器列表或网络流量。最多支持八个节点，超出时拒绝该次快照，避免静默遗漏。

## 凭证与恢复

Wi-Fi 和令牌保存在本机 NVS。未启用 Flash 加密，能够物理读取 Flash 的人可能取得凭证。请使用专用只读令牌，在停用设备时吊销，禁止将凭证提交到仓库。页面不会回显已保存凭证。配网采用 WPA2、单客户端、随机密码，无外部资源，响应禁止缓存并检查浏览器 Origin。没有暴露到互联网的配网接口。保存失败时停留配网模式。NVS 错误不会自动擦除数据。

完成真实联网测试需要用户在配网页面提供 Wi-Fi 与有效只读令牌。不会把浏览器登录会话复制进固件。

## 编译与验证

使用 ESP-IDF 5.5.3，运行 `./tools/validate.sh`。包含监控数值与阈值和容量测试、Grafana JSON 帧/状态/时间戳/空值测试、ESP32-C3 编译及合并镜像校验。解析测试链接 IDF 的 cJSON 源码，需要设置 IDF_PATH。设备测试还需覆盖配网、TLS、有效和无效令牌、实时刷新、Wi-Fi 断线、按键及电量。编译成功不等同于设备验证成功。

## 来源与设备验证

BSP、构建配置和镜像校验器来自 [FoloToy/ai-passport](https://github.com/FoloToy/ai-passport)，上游基准为 `3d685a9`，保留其 MIT 许可证。监控应用为本项目新增。未内置 Wi-Fi 密码或 Grafana 令牌。

已通过完整上游测试门禁，并在 ESP32-C3 v1.1 / 8 MB AI Passport 上刷写、校验并观察启动日志；显示驱动、电量计、按键驱动及配网 AP 启动正常。真实联网刷新、屏幕外观和按键交互仍待用户配置后验证。
